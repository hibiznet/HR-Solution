# HiBizNet HR - Attendance CRUD Demo Integrated Package

포함 범위:
- backend/: Spring Boot + JWT + Redis Refresh Token + MariaDB 기준
- frontend/: React + Vite 관리자 포털
- 완전 구현 모듈: 인증, 대시보드, 직원 관리, 부서 관리, 감사 로그, 근태 관리 CRUD

근태 관리 주요 기능:
- 근태 목록 조회(페이징/필터)
- 근태 단건 상세
- 근태 등록/수정/삭제
- 역할/조직 기반 접근 제어
- local profile 데모 데이터 시드
