이 통합본은 기존 근태 CRUD 데모 버전에 다음 3개 모듈을 추가한 확장 패키지입니다.

1. 휴가 관리
   - 휴가 정책 CRUD
   - 휴가 요청 CRUD
2. 사용자/권한 관리
   - 사용자 CRUD
   - 역할 조회 및 역할 매핑
3. 코드 관리
   - 코드 그룹 CRUD
   - 코드 상세 CRUD

주의:
- 소스는 데모/개발 가속 목적의 베스트에포트 통합본입니다.
- 이 환경에서는 Gradle/npm 최종 빌드 검증까지는 완료하지 못했습니다.
- MariaDB 기준이며, 일부 타입 매핑은 기존 패키지와 동일한 전제를 따릅니다.
